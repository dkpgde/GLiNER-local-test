# Data

Raw and processed datasets are intentionally excluded from Git.

- Download ProcessChat from <https://github.com/IBM/ProcessChat>. Its repository
  states that it is a GPL-3.0-derived research dataset and is not for commercial
  use; review those terms before using it.
- Download DialogPII from <https://doi.org/10.5281/zenodo.20863452>.

The preparation commands in the project README accept the official files
directly. Do not commit source data, manual annotations containing sensitive
material, or generated predictions without an explicit data-governance review.
